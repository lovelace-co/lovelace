# ADR-0001: File cache instead of a database

## Status

Accepted

## Context

Forecast data is small (hundreds of locations, a few kilobytes each), replaced wholesale every hour, and read by a single process. A database adds an operational dependency for no querying need.

## Decision

Cache forecasts as one JSON file per location, written to a temporary name and renamed atomically.

## Consequences

- Zero infrastructure; the cache is inspectable with `cat`.
- Listing across locations requires reading every file; acceptable at this scale.
- Revisit if locations exceed ten thousand or multi-process writes appear.
