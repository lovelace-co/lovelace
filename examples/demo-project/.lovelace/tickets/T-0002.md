## Description

`GET /forecast/:location` returns the cached seven-day forecast for a location slug, 404 for unknown slugs, 503 when the cache is cold. It serves from the file cache described in [[architecture-overview]].

## Acceptance criteria

- [ ] Endpoint serves from cache only; no inline upstream calls.
- [ ] Unknown slug returns 404 with a JSON error body.
- [ ] Cold cache returns 503 with `Retry-After`.
- [ ] Integration tests cover all three cases.
