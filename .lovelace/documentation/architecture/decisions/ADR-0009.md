# ADR-0009: Hook-driven agent presence

## Status

Superseded by [[ADR-0012]].

## Context

The live-ticket thread (the orbiting signal on a card an agent is working) was driven by an inference engine: file-watcher events inside `.lovelace/` raised an energy value that decayed with a 14 second half-life, and the thread showed while energy sat above a threshold. A working agent barely touches `.lovelace/` between tool calls against the wider repository, so the thread died about a minute after the last Lovelace write while the agent was mid-flight, and elapsed time measured the energy's age rather than the work's. The engine existed to be source-agnostic (hand edits, any tool), but for the one claim the thread makes, both ends of the true signal are already ours through the Claude Code hooks.

## Decision

Presence is a marker file written at turn boundaries by the agent helper, and read plainly by the app.

- `UserPromptSubmit` writes `state/presence.json` (`ticket`, `actor`, `started_at`); `Stop` and `SessionEnd` remove it. The helper commands are `presence-start` and `presence-clear`; `install_claude` registers the hooks. Presence is a display signal, so the helper never blocks a turn on its account.
- The app derives liveness with no simulation: the marker exists and is younger than the stale cap, or the project is still. Elapsed minutes are `now` minus `started_at`.
- The stale cap guards against sessions that die without their end hook firing. It defaults to 120 minutes and is configurable per project via the optional manifest key `presence_timeout_minutes` (Settings, General), for long-running work.
- Spec 2.1.0 records the manifest key and the marker file. The energy, half-life, decay and threshold machinery is deleted; the user interface (the thread, the seat dot, elapsed minutes) is unchanged.

## Consequences

- The thread runs for the whole time an agent is processing and rests between turns, matching the truth rather than trailing it by a decay curve.
- A hard-killed session can show live until the cap expires; that is the accepted cost of keeping the design at two hook commands and a timestamp, and the cap is user-tunable.
- Agents without the hook integration no longer light the thread at all; file activity alone was never strong evidence of a working agent, and the false-negative replaces a misleading false-positive.
- No new MCP tools; the seven-tool constraint stands. The marker is machine-local under `state/`, already gitignored.
