## Approach

## What happened

Root cause found: siblingCommands() (packages/mcp/src/host.ts:67) derives sidecar paths from process.execPath, which on Windows is a backslash path, and writeHooks() (packages/mcp/src/claude.ts:154) writes it verbatim into .claude/settings.json; Claude Code runs hooks through bash, which strips the backslashes. Filed as T-0143 with proposed fix (forward-slash normalisation plus quoting, migration of stale entries, and the space-splitting hazard in writeMcpJson). While filing, the first create_ticket call reused ID T-0139 and silently overwrote the done ticket "Sign and notarise macOS release builds": the gitignored counter files under .lovelace/state/counters had drifted behind the on-disk entities (T at 139 with T-0142 existing, S at 135 with S-0138 existing). Recovered T-0139.md from Git, advanced both counters to 142 and 138, re-filed the hooks bug as T-0143, and filed the counter/overwrite data-loss bug as T-0144 (urgent).
