## Approach

Rework the List multi-select per user feedback (checkboxes replacing cmd or ctrl click) and extend the whole flow to the Board view, delegated to the programmer subagent and audited.

## What happened

Hovering a row or card now swaps the status dot for a checkbox in the same leading slot; ticking one enters checkbox mode where every row or card shows its checkbox, and unticking the last exits it. Modifier-click selection was removed; shift-click on a checkbox extends the range in visible order, a plain click opens the ticket and keeps the selection. The bulk bar and delete confirmation were extracted into a shared BulkActions component (owning the modal state and Escape handling) used by both List and Board; the 25 existing List tests passed unmodified against the extraction, and 7 Board tests were added including a drag regression check. Checkbox reuses the existing punched-hole species. 346 tests green sequentially, build clean.
