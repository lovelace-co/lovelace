Turn the existing no-.lovelace init modal into a guided, configurable wizard, with core owning the default workflow and validation as the single source of truth.

New InitWizard (Project / Statuses / Types & Fields / Review) seeded from host.defaultWorkflow(), with a Use defaults fast path and a full field editor (type, required, enum values, refs); Welcome opens it when detect is false. Unmodified configs take the default path so fixtures and determinism are untouched. SPEC unchanged (no format change). 197 tests across the monorepo, incl. new core serialize/init, mcp op, and wizard tests.
