## What happened

Implemented and verified locally. New .github/workflows/release.yml: on a v* tag, four matrix builds (darwin-aarch64, darwin-x86_64 cross-compiled, windows-x86_64, linux-x86_64) each compile sidecars fresh, run the serial test suite and tauri build; a version guard (tag = v + tauri.conf.json = root package.json) and a fail-fast on a missing TAURI_SIGNING_PRIVATE_KEY run before any spend; Apple and Windows code signing engage only when secrets exist and otherwise warn in the job summary; macOS DMGs use the documented headless hdiutil workaround; a release job assembles latest.json mechanically and creates a draft GitHub Release. Supporting scripts: packages/mcp/scripts/bundle.mjs (target-aware Bun compilation), prepare-sidecars.sh extended for cross-compilation with .exe handling, scripts/release/latest-json.mjs (dependency-free, loud failures, sorted keys, optional --notes which I added so T-0117's spec-major rule has a mechanism).
