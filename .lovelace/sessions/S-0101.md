## Approach

Make ticket detail titles wrap over multiple lines instead of truncating, and move the delete button to the top right of the Properties panel heading. Orchestrated per CLAUDE.md: scout mapped the title input, delete button and Properties panel; a programmer agent implemented from a brief; I audited the diff, re-ran the desktop suite and added one boundary fix myself.

## What happened

The title input became a textarea (rows 1, same class, aria-label and commit semantics: Enter commits without inserting a newline, Escape reverts, blur commits) with a useLayoutEffect auto-grow keyed on the draft and ticket id. app.css .view-title-input gained display block, width 100 percent, line-height 1.25, resize none and overflow hidden, and lost text-overflow ellipsis; the bleed margin and padding stay so the title keeps the shared left edge. The delete button moved unchanged into .props-heading, now a space-between flex row; the class is shared with the Children heading, which has a single child, so that heading is unaffected. Tests: title-element casts updated and a new red-first-proven test that Enter commits and cancels the newline. On audit I also set the header row to align flex-start with a 6px optical margin on the Back button so a wrapped title does not float the button mid-height. Desktop suite 229 tests pass; full pnpm test (276) and build passed in the programmer run and a combined final run happens at end of session.
