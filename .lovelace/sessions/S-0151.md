## What happened

New .integration-row and .integration-panel styles use only the tokens (seat radius, raise surface, the metre, motion tokens) with negative margins so surfaces bleed into the gutter and labels keep the shared left edge; the global button reset supplies border and cursor. All copy is unchanged; tests updated to open a row first plus four new tests (at-rest control count, one-panel-at-a-time, at-rest state per status shape, checkbox state persistence across close and reopen).
