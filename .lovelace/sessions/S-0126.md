## Approach

User reported that clicking Edit on a ticket and typing did nothing. Traced the edit flow with a scout, then ruled out the other suspects by reading the code: the editor mounts fresh with editable true, the global keydown handler only intercepts Cmd/Ctrl W, T and N, the capture-phase handler on .body-editor only takes Cmd/Ctrl Enter, and every pointer-events and user-select rule in app.css is scoped to other components. The cause is focus: the Edit button unmounts when clicked, focus falls to the document body, and BlockEditor never focuses the Lexical editor, so keystrokes go nowhere until the user clicks inside the text. Fixed by mounting Lexical's AutoFocusPlugin in BlockEditor whenever it is not read-only; all three mounts (ticket body, comment composer, document editor) are edit-on-intent, so focusing on mount is always right and honours ADR-0010.
