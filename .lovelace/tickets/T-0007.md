## Description

User feedback on the liquid glass build: too much colour, too tight, generic fonts, glass everywhere. Calibrate toward Linear: aurora reduced to a whisper, flat bordered sidebar with icons and subtle selected states, distinguished sticky page header, depth from type size rather than caps and weight, glass reserved for modals and the header, Inter plus Geist Mono, more air throughout.

## Acceptance criteria

- [x] Aurora opacity cut to a corner tint.
- [x] Sidebar flat with border, icons, no left-bar selected state.
- [x] Sticky page header panel with large title.
- [x] Labels no longer uppercase; headings scale by size.
- [x] Glass only on modals, backdrop and sticky header.
- [x] All component tests pass.
