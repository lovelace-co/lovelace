## Description

Replace the enforced CONTEXT.md + per-directory OVERVIEW.md with a single optional index.md in a documentation/ root, drop filename enforcement, and inform rather than enforce. Spec bumps to 2.0.0. See ADR-0008.

Because bumping core to spec major 2 makes the host reject 1.x projects, the core bump, both fixtures, the app, and both live-repo migrations must land together to stay consistent.

## Acceptance criteria

- [ ] index.md in documentation/ is the entry; no CONTEXT.md / OVERVIEW.md required.
- [ ] Filenames unrestricted; the app locks nothing.
- [ ] Validator no longer warns about missing landings; tools prefer index.md and degrade gracefully.
- [ ] Demo fixture and this repo migrated to 2.0.0; pnpm build and pnpm test pass.
