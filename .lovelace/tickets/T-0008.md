## Description

Give the app its signature: presence derived from real file-watcher events. External activity raises project energy; stillness decays it. The atmosphere wakes and breathes, changed tickets glow with recency, the focused ticket wears an agent-at-work chip, the sidebar reports who is working on what, and the digest types itself on like agent output.

## Acceptance criteria

- [x] Presence is driven only by external changes; app mutations never trigger it.
- [x] Energy decays to stillness within about a minute of silence.
- [x] Per-ticket glow fades with recency.
- [x] prefers-reduced-motion renders everything statically.
- [x] Engine and TypeOn covered by tests.
