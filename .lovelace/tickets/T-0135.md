## Description

In the block editor toolbar (`apps/desktop/src/editor/BlockEditor.tsx:402-410`), the three reference buttons, Link a ticket, Link a document and Link a file, render their icons visibly off-centre vertically compared with every other button in the toolbar.

The likely cause is that these three are the only `.tool` buttons whose content is an SVG component (`TicketIcon`, `DocsIcon`, `FileIcon` from `apps/desktop/src/components/icons`) rather than a text glyph. Inline SVGs sit on the text baseline by default, which pushes them below the visual centre that the text glyph buttons (undo, redo, B, I, `<>`, the link infinity sign) share. The `.tool` styling lives at `apps/desktop/src/styles/app.css:2819`.

## Acceptance criteria

- The ticket, document and file icons sit visually centred within their buttons, matching the vertical alignment of the text glyph buttons in the same toolbar.
- The fix is a shared rule (for example flex centring on `.tool`, or `display: block` on the icon SVGs within it), not per-icon pixel nudges.
- No other icon usage regresses: `TicketIcon`, `DocsIcon` and `FileIcon` are shared components, so check their other call sites still render correctly.
- Styling uses the existing design system tokens; no ad-hoc spacing values.
