## Description

Users without horizontal scroll input could not reach off-screen columns. Add full-height edge panels: a right panel that scrolls the board right, shown only when more board exists that way, and a left panel shown once scrolled. Each fades the columns beneath with a canvas-tone scrim and centres a chevron chip.

## Acceptance criteria

- [x] Right arrow appears only when the board overflows right; left appears only when scrolled.
- [x] Clicking scrolls by ~three quarters of the viewport, smoothly.
- [x] Arrows track scroll, resize, and column-count changes.
- [x] Tests cover the visibility and scroll logic.
