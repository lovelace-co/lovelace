## Description

Dates and times render via Intl with the runtime locale (which reflects the OS in the Tauri webview): US machines get month-day order and 12-hour time, UK and Australian machines get day-month and 24-hour, automatically. Stored values stay ISO; only display is localised.

## Acceptance criteria

- [x] One datetime utility used by the ticket fields, activity and sessions.
- [x] Pure dates never shift across the day boundary.
- [x] No raw ISO strings shown to users.
