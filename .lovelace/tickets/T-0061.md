## Description

Build views/Settings.tsx: one level of tabs (General, Statuses, Types & fields, Automations, Team, Integrations), mirroring the onboarding wizard's order and wording. A purpose line per section; a Save/Discard bar where a section has a draft.

- Statuses and Types & fields share one useWorkflowDraft instance, so a single Save bar spans both.
- The Automations tab reuses the existing rules editor.
- New editors: GeneralSettings (editable name + read-only id/path/spec/created, via writeManifest), TeamSettings (actor rows via writeActors), IntegrationsSettings (install/reinstall Claude assets + git hook via installClaude).

## Acceptance criteria

- [ ] Settings routes among the six tabs with a single tab level (no nested tabs).
- [ ] Renaming the project, editing the team, and installing integrations work end to end.
- [ ] Statuses and Types & fields share a single save.
