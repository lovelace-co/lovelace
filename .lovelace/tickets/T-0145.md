## Description

When Lovelace initialises a new project, the scaffolded `schema.yaml` tags the `done` status with `agent: complete` (`packages/core/src/init.ts`, around lines 76 to 81), and `in_review` carries no agent role. That means an agent finishing a ticket moves it straight to Done with no human review step.

The default for a new project should instead tag `in_review` with `agent: complete`, so agent-finished work lands in review by default and a human promotes it to Done. This matches how this repository's own `.lovelace/schema.yaml` is configured.

## Scope

- `packages/core/src/init.ts`: move `agent: complete` from `done` to `in_review` in the scaffolded status list.
- `examples/demo-project/.lovelace/schema.yaml`: the canonical fixture carries the same `agent: complete` on `done` (line 65); update it to match so the fixture reflects the new default.
- Update any core tests that assert the scaffolded schema or the fixture's status roles.

## Acceptance criteria

- Initialising a new project produces a `schema.yaml` where `in_review` has `agent: complete` and `done` has no agent role.
- The demo fixture matches the new default and remains valid.
- `pnpm test` and `pnpm build` pass.

## Non-goals

- No change to status names or to the set of statuses scaffolded.
- No migration for existing projects; their schema.yaml stays as the user has it.
- No spec version bump: agent role placement is project data, not a format change.
