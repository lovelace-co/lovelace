Wire the Apple Developer credentials into the release pipeline so macOS builds ship signed and notarised.

The workflow already reads the six APPLE_* secrets and degrades gracefully when they are absent; this task sets the real values and proves a signed run.

Acceptance criteria:

- All six APPLE_* secrets set on the repository (certificate, certificate password, signing identity, Apple ID, app-specific password, team ID).
- A release run completes with HAS_APPLE_SIGNING=true and produces DMGs whose app passes a Gatekeeper assessment without warnings.
- Windows signing remains a separate decision (Azure Trusted Signing or a cloud HSM) and is out of scope here.
