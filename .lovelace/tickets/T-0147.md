## Description

The ticket detail view shows the ticket ID in the Properties panel (the ID row, for example T-0132), but there is no quick way to get that ID into the clipboard. Users copy ticket IDs constantly, into commit messages, chat and session records, and today that means selecting the text by hand.

Add a small copy icon next to the ticket ID. Clicking it copies the bare ticket ID (for example `T-0132`) to the system clipboard.

## Requirements

- The icon sits beside the ID value in the Properties panel, quiet at rest and consistent with the control species rules (a pressing control, not ad-hoc styling).
- Copies the ID exactly as it appears in the file, preserving its casing (for example `T-0132`), with no surrounding whitespace or extra text.
- Works on macOS, Windows and Linux. Use the clipboard mechanism that works inside the Tauri webview on all platforms rather than assuming the browser clipboard API is available.
- Give brief visual feedback that the copy happened (for example the icon swapping to a tick for a moment). No toast machinery if a lighter affordance does the job.
- Keyboard accessible: the control is focusable with the standard cyan focus ring and has an accessible label.

## Acceptance criteria

- Clicking the icon puts the bare ticket ID on the clipboard on macOS and Windows.
- The resting state of the Properties panel stays visually quiet; the icon does not compete with the ID text.
- `pnpm test` and `pnpm build` pass.

## Non-goals

- No copy affordances elsewhere (board cards, list rows); this ticket covers the ticket detail Properties panel only.
- No copying of anything other than the ID (no title, no URL).
