## Why

Inserting a diagram is hard to discover. Today it works through the slash menu (`/`) and through the Diagram entry in the toolbar's block-type dropdown (both call `insertMermaid`), but there is no visible one-click affordance. Add a dedicated toolbar button, like the ticket, document and file reference buttons.

## What

- Add a diagram button to the `Toolbar` in `apps/desktop/src/editor/BlockEditor.tsx`, in the reference-buttons group after the file button, with a fitting icon in `apps/desktop/src/components/icons.tsx` and `aria-label`/`title` "Insert a diagram".
- Clicking it calls the existing `insertMermaid(editor)` (`apps/desktop/src/editor/MermaidNode.tsx`), which inserts a fresh mermaid block and opens the source modal; cancelling the modal removes the new block, as it already does from the slash menu.
- No new insertion path: the button reuses `insertMermaid` exactly as the slash menu and block-type dropdown do.

## Acceptance

- The button renders in the toolbar for editable editors only (not read-only) and matches the existing `.tool` button treatment.
- Clicking it inserts a mermaid block and opens the edit modal; saving keeps the block, cancelling removes it.
- A rendering test asserts the button exists and dispatches the insert (house style, `apps/desktop/test/editor.spec.tsx`).
- `pnpm test` (desktop) and `pnpm build` pass.
